▸One-time setup for “Send to CMS” (Chrome)

Click to expand

Do this once per computer. After that, Send to CMS fills the New Client form in one click. The script only reads the lead data from the link and never presses Save Client.

  1. Install the Tampermonkey extension from the Chrome Web Store.
  2. In Chrome go to chrome://extensions → Tampermonkey → Details → turn on Allow User Scripts. If that switch isn’t there, turn on Developer mode (top-right of the Extensions page) first. Without this, Chrome silently disables every script.
  3. Open the script link: securityusa-cms-autofill.user.js. Tampermonkey shows an install page — click Install. (If you only see code as plain text, Tampermonkey isn’t active yet — go back to step 1–2.)
  4. Check: click the Tampermonkey icon → Dashboard. “Security USA CMS – lead autofill” should be listed with its switch on.
  5. Fill the cheat sheet, click Send to CMS →. The CMS opens with every field filled and a blue banner at the top — review, then click Save Client yourself.

Not working? Make sure you’re logged in to the CMS, that step 2 is on, and reload the CMS tab once after installing. If it still doesn’t fill, use the fallback prompt under step 7 with Claude in Chrome.

Fields save in this browser as you type. “New call” clears them.
